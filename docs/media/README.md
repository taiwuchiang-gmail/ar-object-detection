# Yellow duck preview

The MP4 is a 720 x 540 re-encoding of the complete historical annotated Python result (50.47 seconds, 30 fps, 1,514 frames). The GIF is a continuous excerpt from seconds 20–28 at reduced size and frame rate. The PNG shows a representative midpoint frame.

Detection boxes and confidence labels are already present in the source recording and remain unchanged apart from image resizing. No model was retrained or run for this export. Exact historical checkpoint/threshold details were not recovered from the video itself; these files demonstrate the saved result rather than a newly verified training run.

Use `exportDuckDemo` to regenerate them from the local original recording. The JSON contains source filename, dimensions, timing, and export details; no local machine paths are published.
